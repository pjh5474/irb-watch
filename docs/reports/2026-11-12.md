# Daily report: 2026-11-12

## Summary
Two features across both repos, each asked first, built, reviewed and migrated:
- **Hospitals:** a hospital now groups its boards. Projects, IRB pipelines, per-hospital step orders, guides and form templates belong to the hospital, not to one board. Committed by the owner.
- **IRB pipeline, phase 3 of 4:** every AI draft and AI revision runs as a background job with a status, and each pipeline step has "Draft for this step", written from the user's own step files.

Two migrations were applied today (33 in all), each dry-run first and checked read-only afterwards. Everything else is tested offline only: nothing from today has run in a browser or against the real model.

## Decisions made today
- **Hospitals:**
  - a platform-wide catalog edited by the platform admin; organizations never own a hospital;
  - every board belongs to one hospital and has a kind from a fixed list;
  - any hospital can be added to a project and get a pipeline; board documents stay gated per board;
  - guides and form templates belong to the hospital;
  - a members-only manual source must name its hospital, because hospital names are public.
- **Draft jobs:**
  - all drafts and revisions run as jobs, standalone ones too;
  - 2 open per user, 1 per step, the same daily limit;
  - a job open at a server restart is failed with a reason, never re-run;
  - status on the page only, no mail.
- **Step drafts:**
  - this step's and earlier steps' files are ticked by default; the user can untick;
  - the dialog's file list is the consent;
  - board documents are picked by the user, form-box board first;
  - several drafts per step;
  - a revision whose own files are gone is refused with what to do (kept, not "drop the file and revise").
- **Tests:** the suites stay as they are; no pruning by count.
