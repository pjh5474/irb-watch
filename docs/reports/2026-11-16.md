## 1. Owner decisions (three question rounds)
- **Scope:** copying to siblings only. "Use draft as final file" and "made from draft" wait, because the docs generator is hidden in the frontend.
- **What is copied:**
  - the type, subject and slot layout (order, the user's own slots, "not needed" marks);
  - **plus the due date and the target meeting.**
- **What is never copied:** files, drafts, notes, status, result, and the submitted and decided dates.
- **When the sibling already has a step of that type:**
  - an untouched step is filled;
  - a step with work is skipped and named.
- **Filling:** only the empty fields are filled; what someone typed there stays.
- **Numbered types:** an untouched step is filled first; otherwise a new step gets the sibling's next number.
- **Follow-ups:** not copied; only main steps are.
- **Free steps:** copied, always as a new step.
- **Link:** the step page shows "Copied from <site> · <step>". There is no sync, and a site that already has a copy is skipped.
- **Sibling with no pipeline:** shown and skipped ("start it first").

## 2. Defaults I chose (please check)
- **"Untouched" step** has all of these:
  - live, a main step, and not itself a copy;
  - open and not submitted;
  - no submitted or decided date, and no result;
  - no live follow-ups;
  - no file in any slot, removed slots included.
  - **Drafts do not count.**
- **Several untouched steps of a numbered type:** the lowest number is filled.
- **A step that is already an untouched copy of another site's step** is skipped. The reason says "already a copy of another PI's step"; it is not called work and gets no second round. I found this after the first build: before the fix, it showed a false "has work" or added a duplicate 2차.
- **Slot matching:**
  - by the list row first, then by name in any case;
  - a matched slot takes the source's order and its "not needed" mark (otherwise it becomes needed);
  - source slots with no match are added;
  - the target's other slots stay and go last.
- **A target meeting that is no longer valid** (cancelled or hidden) is not copied, and that site gets a note.
- **Limits:** a sibling at 60 steps, or a step that would go over 60 documents, is skipped with the reason.
- **Access:** both the preview and the copy need edit access.
- **When every chosen site is skipped:** nothing is written, and the answer is a 409 listing each reason. It never looks like "no change".
- **The copy dialog opens on demand.** The step page makes no extra call for it, and the button shows on every main step you can edit, even when the hospital has one PI. The dialog then says "no other PI".
- **"Copied from" line:** shown only on a copied step. It costs **3 extra database reads** on that step's page, about 1.2-1.8 s on today's server.
- **The preview and the copy each cost about 10-12 database reads,** whatever the number of sites. On today's server that is **about 4-7 s each**, and the copy plans again before writing.
- **Restoring a removed copy** while another live copy exists is refused with the reason.
